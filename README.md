# Curtain Website

A showcase website for a small curtain business, displaying different curtain designs created by the business owner.

## Tech stack

- HTML, plain JavaScript
- Tailwind CSS
- Vite

## Run it locally

1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
3. Open the address shown in the terminal (usually http://localhost:5173)

## Status

Work in progress. First goal: a minimal viable version for showcasing.
